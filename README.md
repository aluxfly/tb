# 🎯 智能投标匹配系统（Phase 1 MVP）

免费、开源的招标信息监控与匹配平台。

---

## ✨ 功能特性

- ✅ **实时招标列表**：展示国家电网 ECP 平台最新招标信息
- ✅ **智能匹配度**：根据你的企业资质自动计算匹配度（地区+资质）
- ✅ **资质管理**：添加/删除你的企业资质，实时更新匹配评分
- ✅ **详情查看**：点击查看项目详情，一键跳转 ECP 平台原文
- ✅ **免费托管**：GitHub Pages 零成本部署
- ✅ **自动更新**：每日 2:00 自动抓取最新数据（GitHub Actions）

---

## 🚀 快速开始

### 1. 本地运行（无需安装）

直接打开 `index.html` 即可使用（无需服务器）。

或启动本地服务：
```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

### 2. 使用说明

1. **标讯列表页**：
   - 查看今日招标信息
   - 使用搜索框筛选关键词
   - 使用地区下拉框筛选地区
   - 查看匹配度标签（红/黄/绿）

2. **我的资质页**：
   - 输入资质名称（如"ISO9001"、"电力施工总承包"）
   - 点击"添加"保存到 LocalStorage
   - 返回列表页查看匹配度变化

3. **更新数据**：
   - 点击右上角"🔄 更新数据"按钮
   - 触发 GitHub Actions 重新抓取（需要网络）
   - 或等待每日自动更新（凌晨 2:00）

## 📊 匹配度算法

| 规则 | 分值 |
|------|------|
| 地区匹配 | +30分 |
| 每项匹配资质 | +20分 |
| 预算达标（>100万） | +10分 |
| **最高** | **100分** |

## 🏗️ 项目结构

```
smartbid-mvp/
├── index.html              # 主应用（单文件，Tailwind CSS）

├── .github/
│   └── workflows/
│       └── update-tender-data.yml  # 自动更新工作流
└── README.md
```

## 🔄 部署到 GitHub Pages

1. 创建仓库 `your-username/tb`
2. 推送代码到 `gh-pages` 分支
3. 启用 Pages：Settings → Pages → Source: `gh-pages` branch
4. 访问 `https://your-username.github.io/tb/`
